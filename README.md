# Color by Number Rewards

Prototype for a standalone Color-by-Number game.

## Current prototype
- Number/color image stages
- Image completion rewards
- Brush global reward multiplier
- Brush upgrade economy
- Local browser save using localStorage
- Responsive UI
- Vite build suitable for Cloudflare Pages

## GitHub / Cloudflare
Build command:
`npm run build`

Output directory:
`dist`

Connect the GitHub repository to Cloudflare Pages. Every push to the selected production branch can trigger a new deployment automatically.

## Important
This prototype stores progress locally in the browser. For real users/accounts and secure Coins, move Coins, rewards, upgrades, and image completion validation to a server/backend before launch.
